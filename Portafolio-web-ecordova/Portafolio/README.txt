PÁGINA WEB DE ESTUDIOS - BASADA EN LAS GUÍAS 01 A 05 DE IDAT

Contenido utilizado:
- Guía 01: estructura HTML, títulos, párrafos, enlaces y secciones.
- Guía 02: CSS, selectores, clases, colores, márgenes y padding.
- Guía 03: Bootstrap, contenedores, filas, columnas, tarjetas y menú responsive.
- Guía 04: JavaScript y variables.
- Guía 05: funciones, eventos y addEventListener.

ARCHIVOS
- index.html
- css/estilos.css
- js/script.js

CÓMO ABRIR
1. Descomprime el ZIP.
2. Abre Visual Studio Code.
3. Selecciona Archivo > Abrir carpeta.
4. Abre la carpeta pagina_estudios_guias_idat.
5. Abre index.html en el navegador o usa Live Server.

Bootstrap está enlazado desde CDN, por eso necesitas conexión a Internet para que sus estilos y el menú responsive se carguen correctamente.

Puedes cambiar los textos dentro de index.html, los estilos dentro de css/estilos.css y el comportamiento del botón dentro de js/script.js.
